# نسخ سطح المكتب — ميزان الشمس

التطبيق ملف HTML واحد يعمل في أي متصفح. هنا طريقتان لتشغيله كبرنامج
ويندوز (`.exe`) بأيقونة على سطح المكتب ونافذة مستقلة بلا شريط متصفح.

| | المشغّل الصغير | تطبيق Electron |
|---|---|---|
| الحجم | **١٫٦ ميغا** | **٣٢٦ ميغا** (١٣١ مضغوطاً) |
| يحتاج متصفحاً في الجهاز | نعم — Edge أو Chrome | لا، مستقل تماماً |
| التحديث | ملف واحد يُستبدل | إعادة بناء كاملة |
| الأنسب لـ | الاستعمال اليومي | جهاز بلا متصفح حديث |

كلاهما يفتح نفس التطبيق بنفس البيانات (المزامنة عبر Firebase مشتركة).

---

## ١) المشغّل الصغير — `launcher/`

ملف `.exe` واحد يحمل التطبيق بداخله كمورد. عند التشغيل يفكّه إلى
`%LOCALAPPDATA%\MizanAlShams\app.html` ثم يفتحه بنافذة مستقلة
(`--app`) مستعملاً Edge أو Chrome الموجود في الجهاز.

يستعمل **مجلد بيانات متصفح مستقلاً** للتطبيق، فبيانات
`localStorage` تبقى بين التشغيلات ولا تضيع إن مسح المستخدم تاريخ
تصفحه، ولا تختلط بجلساته العادية.

### البناء

```bash
sudo apt-get install -y mingw-w64
pip install pillow
./launcher/build.sh          # ← MizanAlShams.exe
```

### الاختبارات

```bash
sudo apt-get install -y wine64
./launcher/run_tests.sh
```

تتحقق من ترميز عنوان `file://` (أسماء مستخدمين عربية، مسافات،
محارف تكسر سطر الأوامر)، ومن إنشاء مجلد البيانات، ومن البحث عن
المتصفح.

---

## ٢) تطبيق Electron المستقل — `electron/`

يحمل متصفحه بداخله فلا يعتمد على أي برنامج في الجهاز.

### البناء

```bash
cd electron
npm install
npm run package:win          # ← dist/MizanAlShams-win32-x64/
```

من لينكس: ثنائيات Electron تُجلب من GitHub افتراضياً؛ إن كان محجوباً
اضبط مرآة:

```bash
export ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/"
```

وضبط أيقونة الـ exe يمرّ عبر `rcedit` وهو برنامج ويندوز، فيحتاج
`wine64` على لينكس — وبدونه يُبنى التطبيق سليماً بأيقونة Electron
الافتراضية.

### الاختبار

```bash
cd electron
xvfb-run -a ./node_modules/.bin/electron --no-sandbox test_main.js
```

يشغّل الغلاف فعلياً ويتحقق أن النافذة فُتحت وأن التطبيق حُمِّل
بأقسامه و`localStorage` يعمل.

---

## البناء عبر GitHub

`.github/workflows/build-windows.yml` يبني النسختين عند كل تعديل على
ملف التطبيق أو على `desktop/`، ويرفعهما ملفّين جاهزين للتنزيل من
صفحة **Actions** في المستودع. يمكن تشغيله يدوياً من هناك أيضاً
(**Run workflow**).

بسبعة أحجام من ١٦ إلى ٢٥٦ بكسل.
