# اختبارات ميزان الشمس

اختبارات تعمل على **متصفح حقيقي** (Chromium عبر Playwright) لا على محاكاة —
تفتح التطبيق، تسجّل الدخول، تزرع بيانات، وتقيس النتيجة كما يراها المستخدم.

## التشغيل

```bash
npm install          # مرة واحدة
npm test             # كل المجموعات
node tests/run.js t_pay tz     # مجموعات بعينها
```

إن كان متصفّح Chromium في مسار آخر:

```bash
CHROME=/path/to/chrome npm test
```

## الفكرة

الاختبارات تقيس **ثوابت** لا حالات مفردة — الثابت المكسور يكشف العطل أينما كان:

- المدفوع لا يتجاوز المستحق أبداً، في كل مسارات الدفع.
- المال لا يعبر بين الأشخاص.
- المجموع = مجموع أجزائه (المحصلة · الجامع · الإحصاء · Excel).
- التعديل لا يُتلف بيانات ولا يُضيّع دفعات.
- الملف المُصدَّر يطابق الشاشة التي صُدِّر منها.
- لا وسم HTML من إدخال المستخدم يُنفَّذ في أي شاشة أو وصل.

## المجموعات

| المجموعة | ما تحرسه |
|---|---|
| `smoke` `crawl` | الإقلاع بلا إنترنت · مرور على ٤٤ تبويبة وكل الأزرار |
| `money` `t_pay` | صحّة الحسابات · مسارات الدفع الستة وأجور النقل بمصادرها |
| `t_owner` `t_bulk2` | **المال لا يذهب لشخص آخر** — الدفع بالهوية لا بالبحث |
| `t_edit2` | حارس التعديل: الأوزان المتناقضة · الفائض الخفي |
| `t_flow` | دورات العمل كاملة · الحذف والاسترجاع · الطابور دون اتصال |
| `t_agg` `t_xl` | صحّة التجميع · مطابقة تصدير Excel للشاشة |
| `t_cash2` | الخزينة: خطّ الأساس · التحويلات · الحركات اليدوية |
| `t_audit` | سجلّ التدقيق · إغلاق الفترات |
| `t_backup` `t_diag` | اللقطات التلقائية · تشخيص الاتصال والصلاحيات |
| `func` `normal` `sweep2` `pinpoint` `visible` `mat` | التهريب: لا وسم يُنفَّذ، ولا وسم موثوق يُعطَّل |
| `tz` | المنطقة الزمنية (بتوقيت بغداد) — الأحد لا يسقط |
| `feat` `gtest` `sell` `t_new` `naqlbug` | الدفع الجامع والشامل · الميزات الجديدة |
| `t_auth` `t_gate` |  ربط الجهاز بحساب · وضع «الحسابات المختارة فقط» — والجلسة لا تُستبدَل بمجهول |
| `t_perf` | تقارير الأداء |
| `t_paygrp` | الدفعة الجامعة سطر واحد — والمجموع لا يتغيّر بالتجميع |
| `t_build` | التقسيم لا يغيّر بايتاً: `src/` ↔ الملف الواحد، وكل جزء JS يصلح وحده |

## عند إضافة ميزة

أضف مجموعة `t_<اسم>.js` على نمط الموجود (انظر `lib.js`)، واجعلها تقيس ثابتاً
لا مظهراً. ثم `npm test` قبل أي نشر.
