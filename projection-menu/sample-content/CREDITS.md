`mixed-grill.webm` (6 s, 1280x720, VP9) is not stock footage: it was rendered
from `mixed-grill.jpg` with ffmpeg (slow push-in + vignette) so the sample menu
has one dish with a video. Same source and license as the photo.

Every media file named in `manifest.json` lives in `images/`.

The photographers' names could not be looked up from the build machine (the
unsplash.com site is behind a bot check); the photo id above opens the original
at `https://images.unsplash.com/photo-<id>`.

Dish names, descriptions and prices are fictional sample data.
